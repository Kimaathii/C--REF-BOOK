# Floor 2 — OOP Pillars

The four pillars that make .NET architecture make sense.

## 📚 The Four Pillars

### 1. Encapsulation
**Bundle data and behavior, hide internals, protect state**

- Location: `Encapsulation/`
- Learn how to bundle related data with methods
- Use access modifiers to protect internal state
- Expose only what clients need

### 2. Inheritance
**Child classes inherit parent — write once, reuse everywhere**

- Location: `Inheritance/`
- Understand `base` keyword and constructor chaining
- Learn what gets inherited and what doesn't
- Avoid deep inheritance chains

### 3. Polymorphism
**One type, many forms — runtime decides behavior**

- Location: `Polymorphism/`
- Virtual methods and override
- Base type references pointing to derived objects
- Runtime behavior dispatch

### 4. Abstraction
**Hide complexity, expose only what matters**

- Location: `Abstraction/`
- Abstract classes and abstract methods
- Contracts without implementation
- Layer of indirection for flexibility

## 🚀 How to Run Each Project

```bash
cd Floor2-OOP/Encapsulation
dotnet run

cd Floor2-OOP/Inheritance
dotnet run

cd Floor2-OOP/Polymorphism
dotnet run

cd Floor2-OOP/Abstraction
dotnet run
```

## 🎯 Learning Order

1. **Encapsulation** — foundational, start here
2. **Inheritance** — building on encapsulation
3. **Polymorphism** — leveraging inheritance
4. **Abstraction** — pulling it all together

---

*These four pillars work together. Master one, understand the next.*
