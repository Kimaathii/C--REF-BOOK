## 🎯 Key Takeaways

- Classes are blueprints; objects are instances
- Access modifiers control visibility and mutation
- Constructors establish contracts at creation
- Properties are controlled gateways to fields
- `static` members belong to the class, not instances
- `readonly` fields prevent reassignment after construction
