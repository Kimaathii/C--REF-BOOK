# Floor 3 — Interfaces & SOLID

Where OOP gets its real superpower.

## 📚 What You'll Learn

| Concept | Description |
|---|---|
| Interfaces | Pure contracts with zero implementation |
| SOLID Principles | Five principles of clean, maintainable code: **S**ingle Responsibility, **O**pen/Closed, **L**iskov Substitution, **I**nterface Segregation, **D**ependency Inversion |
| Abstraction Deep Dive | When to use abstract classes vs interfaces |
| Polymorphism via Interfaces | Many implementations of one contract |

## 🚀 How to Run

```bash
cd Floor3-Interfaces/InterfacesPractice
dotnet run
```

## 🎯 Key Concepts

- **Interfaces define contracts**, not implementation
- **SOLID** makes code flexible and testable
- **Interface Segregation** — clients depend only on methods they use
- **Dependency Inversion** — depend on abstractions, not concretions
